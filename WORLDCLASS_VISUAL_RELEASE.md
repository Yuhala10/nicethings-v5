# NiceThings — World-Class Visual Pass

This release upgrades the shared visual layer across Saved, Profile, Submit, Admin, Admin Login, Privacy and Terms while preserving the existing application architecture and data flows.

## Included
- Premium glass/surface cards, typography, spacing and responsive layouts.
- Consistent NiceThings orange/charcoal design language.
- Visible Admin entry in the desktop header and mobile menu.
- Global EN/FR switcher in the header.
- Shared French translation dictionary and client-side translation bridge for existing hard-coded UI copy.
- Existing GPS, map, Supabase and visitor architecture preserved.
- Privacy/consent experience retained.

## Environment
Keep `.env.local` private. Required production values are documented in `.env.example`.
